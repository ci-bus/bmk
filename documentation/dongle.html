USB dongle

The dongle is a small nRF52840 board that plugs into the computer, connects to a keyboard running BMK over Bluetooth and presents it as a wired USB keyboard.

Why use it

  • The computer sees a plain USB keyboard: it works in the BIOS, on machines without Bluetooth and before the operating system starts.
  • The link is tuned for low latency, since the dongle is powered by the port and does not have to save energy.
  • It works with every keyboard running BMK. The dongle does not need to know the matrix or the keymap.

Hardware

The dongle uses the same base hardware as a keyboard with an nRF52840, without the key matrix: the module, the USB connector and the UF2 bootloader. It has no buttons and no battery.

Build and flash

cd app
west build -p auto -b nrf52840 -d build-dongle -- -DKEYBOARD=dongle

Flash build-dongle/zephyr/zephyr.uf2 as described in Flashing. The keyboard firmware needs no special build to work with the dongle.

Connect a keyboard

  1. Make sure the keyboard has no paired host. If it was paired with a computer, press the key mapped to HID_BT_CLEAR.
  2. Plug the dongle into the computer.
  3. Press a key on the keyboard to wake it up.

The dongle connects on its own within a few seconds and the keyboard starts typing through USB.

How the link works

  • Free keyboards only. A keyboard without a paired host adds a BMK "free" mark to its advertising. The dongle scans continuously and connects to the first keyboard that shows that mark. Keyboards paired with a computer are ignored.
  • Encrypted, never stored. The link is encrypted, but neither side saves the keys. The dongle forgets the keyboard as soon as it loses power, and the keyboard stays free.
  • Automatic reconnection. If the dongle is unplugged or the computer is switched off, the keyboard keeps advertising slowly for five minutes and then turns Bluetooth off. Plug the dongle back in and, if needed, press a key: the link comes back by itself.
  • No stuck keys. When the link is lost, the dongle releases every key on the computer.
  • Wake from sleep. A key press wakes a suspended computer, if its USB port allows it.

Going back to Bluetooth

Unplug the dongle and pair the keyboard with the computer in the usual way. Once it is paired, the keyboard stops showing the free mark and the dongle ignores it.

To return to the dongle, press HID_BT_CLEAR on the keyboard.

Limits

  • One dongle serves one keyboard at a time.
  • The dongle cannot choose between several free keyboards in range. It connects to the first one it hears.

Link parameters

ParameterValue

The Bluetooth values are defined in app/src/dongle/dongle.h; the USB values in app/src/dongle/dongle.conf.

Logs

Set #define LOGS true in app/src/dongle/dongle.h and rebuild with -p always. The dongle then also appears as a USB serial port that prints its activity. See Logs.
