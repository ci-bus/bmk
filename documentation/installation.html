Installation

BMK is built inside a Docker container that already contains the Zephyr SDK and the ARM toolchain, so nothing has to be installed by hand on your machine.

Requirements

  • Docker Desktop (macOS, Windows or Linux).
  • VS Code with the Dev Containers extension.
  • Git.

Set up the workspace

1. Clone the repository

git clone git@github.com:ci-bus/bmk.git
cd bmk

2. Open it in VS Code

code .

3. Reopen in the container

VS Code detects the .devcontainer folder and offers Reopen in Container. Accept it. The first time, Docker builds an image based on zmkfirmware/zmk-dev-arm:3.5-branch, which includes the Zephyr SDK, the ARM toolchain and west.

4. Download Zephyr

In the container terminal, from the root of the repository, run this once:

west init -l app/
west update

This fetches Zephyr 3.6.0 and the modules the firmware needs (cmsis, hal_nordic, mbedtls, tinycrypt and segger). The versions are pinned in app/west.yml.

Zephyr and its modules are stored in Docker volumes, so they survive container rebuilds and you only download them once.

The workspace is ready. Continue with Building.

Docker volumes

VolumeMounted atContent
bmk-zephyrzephyr/Zephyr RTOS source
bmk-modulesmodules/HALs and libraries
bmk-toolstools/Build tools
bmk-bootloaderbootloader/Reserved for bootloader sources; empty with the current manifest
bmk-root-user/rootUser cache and west configuration

Start from scratch

To discard the downloaded workspace, close the container and remove the volumes. The next time you open the container, repeat step 4.

docker volume rm bmk-zephyr bmk-modules bmk-tools bmk-bootloader bmk-root-user
