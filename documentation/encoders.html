Encoders

BMK supports one rotary encoder. Each direction of rotation sends a keycode chosen in the keymap.

Enable the encoder

In keyboard.h:

#define ENCODERS 1

In keyboard.c, give the two pins connected to the A and B outputs of the encoder:

const uint16_t pin_encoders[ENCODERS * ENCODER_PINS] = {
    P0(6),
    P0(5),
};

The common pin of the encoder goes to ground. The firmware enables the internal pull-ups on both pins, so no external resistors are required.

On keyboards without an encoder set ENCODERS to 0. In that case pin_encoders is not needed and the keymap has no encoder entries.

Assign keycodes

Each layer of the keymap ends with two entries for the encoder, one per direction:

const uint16_t layers[LAYERS][MATRIX_COLS * MATRIX_ROWS + ENCODERS * ENCODER_PINS] = {
    {
        /* matrix keys */
        HID_KEY_VOLUME_DOWN, HID_KEY_VOLUME_UP
    },
    {
        /* matrix keys */
        HID_KEY_PREV_TRACK, HID_KEY_NEXT_TRACK
    }};

Each step of the encoder sends a press and a release of the keycode. HID_KEY_TRANS works here as well, to reuse the keycodes of the layer below.

If the encoder works backwards, swap the two keycodes in the keymap or the two pins in pin_encoders.

Push button

The push switch of an encoder is wired like any other key of the matrix and gets its keycode in the normal part of the keymap.

Sleep

Turning the encoder wakes the keyboard up, the same as pressing a key. See Sleep and power.
