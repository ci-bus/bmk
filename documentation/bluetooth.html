Bluetooth

On battery the keyboard works as a Bluetooth Low Energy HID keyboard. It is compatible with macOS, iOS, Windows, Linux and Android.

Pairing

  1. Press any key to make sure the keyboard is awake.
  2. Open the Bluetooth settings of the host and select BMK Keyboard.

Pairing needs no PIN. The link is encrypted, and the keyboard closes the connection if the host does not encrypt it.

One host at a time

The keyboard remembers a single host. After pairing, that host reconnects by itself whenever the keyboard is visible again.

To use the keyboard with another host, press the key mapped to HID_BT_CLEAR. The keyboard then:

  1. Closes the current connection and forgets the paired host.
  2. Takes a new Bluetooth address, so the previous host no longer recognises it.
  3. Restarts and becomes visible for pairing.

After a HID_BT_CLEAR, remove the old BMK Keyboard entry from the Bluetooth list of the previous host. To use that host again, pair as if it were a new keyboard.

When the keyboard is visible

SituationAdvertising
Start-up, or wake-up with Bluetooth offFast (every 100 to 150 ms), until a host connects or the keyboard reaches deep sleep.
The connection is lost or the host disconnectsSlow (every 1 to 1.2 s) for SLEEP_TIMEOUT_ADV seconds (5 minutes by default). If nothing connects in that time, Bluetooth is turned off.
Bluetooth offNone. Press any key to turn Bluetooth on again and advertise fast.

The slow interval saves battery while still letting the host or the USB dongle reconnect by itself, for example after the computer wakes up or the dongle is plugged in again. With the slow interval a reconnection can take a few seconds.

The complete list of power states is in Sleep and power.

Bluetooth and USB together

When the USB cable is connected, key presses are sent over USB only. Bluetooth stays on and a paired host can remain connected, but it receives no keys until the cable is unplugged. See USB.

Free mark for the dongle

A keyboard that has no paired host adds a small BMK mark to its advertising. The USB dongle uses that mark to find keyboards it is allowed to connect to. Pairing with a computer removes the mark; HID_BT_CLEAR brings it back.
