Configuration options

Every keyboard is configured with #define lines in its keyboard.h. This page lists all of them with their default values.

How options work

Open app/keyboards/<vendor>/<keyboard>/keyboard.h and add a line for each option you want to change:

#define DEBOUNCE_PRESS 8
#define SLEEP_TIMEOUT 30

An option that is not defined takes the default shown in the tables. After changing an option, build and flash again. Only RGB and LOGS need a clean build with -p always.

Required

These four must be defined in every keyboard.h.

OptionMeaning
MATRIX_COLSNumber of columns of the key matrix.
MATRIX_ROWSNumber of rows of the key matrix.
LAYERSNumber of layers in the keymap.
ENCODERSNumber of rotary encoders: 0 or 1.

Scanning and debounce

OptionDefaultUnitMeaning
CYCLE_DELAY1000µsPause between two scans of the matrix.
GAMING_CYCLE_DELAY100µsPause between two scans in gaming mode.
DEBOUNCE_PRESS5msTime a key must read as pressed before the press is sent.
DEBOUNCE_RELEASE15msTime a key must read as released before the release is sent.
DEBOUNCE_ENCODER5msTime the encoder must rest before a step is sent.

Debounce times are counted in scan cycles, so the real time is slightly longer than the configured value. If a switch produces double characters, raise DEBOUNCE_PRESS and DEBOUNCE_RELEASE.

Project settings

Settings shared by all keyboards are Zephyr Kconfig symbols in app/prj.conf. The ones you are most likely to change:

SymbolValueMeaning
CONFIG_BT_DEVICE_NAME"BMK Keyboard"Name shown in the Bluetooth list of the host.
CONFIG_USB_DEVICE_PRODUCT"BMK Keyboard"Name shown for the USB device.
CONFIG_USB_DEVICE_VID, CONFIG_USB_DEVICE_PID0x1D50, 0x615EUSB vendor and product ID.
CONFIG_BT_DIS_PNP_VID, CONFIG_BT_DIS_PNP_PID0x1D50, 0x615EVendor and product ID reported over Bluetooth.
CONFIG_BT_DIS_MODEL, CONFIG_BT_DIS_MANUF"BMK Keyboard", "BMK"Model and manufacturer reported over Bluetooth.
CONFIG_BT_CTLR_TX_PWR_PLUS_8yRadio transmit power of +8 dBm.

A change in prj.conf affects every keyboard and the dongle, except where app/src/dongle/dongle.conf overrides it.
