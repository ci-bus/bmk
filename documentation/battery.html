Battery

The keyboard measures its supply voltage and reports the battery level to the host over Bluetooth, where it shows up next to the device name.

How it is measured

The chip measures its own high-voltage supply input (VDDH) internally. No voltage divider and no extra pin are needed on the PCB.

The voltage is converted to a percentage with a curve for single-cell lithium batteries:

VoltageLevel
Below 3.3 V1 %
3.3 V to 3.5 V0 % to 10 %
3.5 V to 3.6 V10 % to 20 %
3.6 V to 3.8 V20 % to 80 %
3.8 V to 3.9 V80 % to 90 %
3.9 V to 4.1 V90 % to 100 %

When it is updated

  • Measuring starts when a host pairs and every time the keyboard wakes up, and repeats every BAT_UPDATE seconds. It stops during sleep.
  • The first reading is used as it is. After that the reported value moves in small steps towards each new reading, so it does not jump when the voltage dips for a moment.
  • The host is notified only when the percentage changes.

Options

Set them in keyboard.h:

OptionDefaultMeaning
BATTERYtrueEnables the battery measurement.
BAT_UPDATE60Time in seconds between two measurements.
BAT_SMOTHING0.1fStep, in percentage points, by which the reported level falls on each measurement. It rises twice as fast.
