Standard keys

Click a key on the keyboard below.

Keys drawn with a dashed border have no named constant. Write their HID usage value directly in the keymap, for example 0x65 for the Menu key. Any other value from the HID keyboard usage table works the same way.

Other controls of the HID consumer page can be sent with (K_CONSUMER | usage), for usages up to 0xFF.

Layer keys

KeycodeAction
FN_MO(1)Layer active while the key is held.
FN_TO(1)Switch to the layer when the key is released.
HID_KEY_TRANSUse the keycode of the layer below.
HID_KEY_NONENo action.

Replace 1 with the layer number. Details in Keymaps and layers.
