USB

With the cable plugged in, the keyboard is a standard USB HID keyboard. No driver is needed on any operating system.

Transport priority

The keyboard detects the USB cable through the supply voltage of the port and chooses the transport by itself:

ConditionKeys are sent over
USB cable connectedUSB
Battery onlyBluetooth

The cable is checked when the keyboard starts, once per second while it is awake, and every time it goes to sleep or wakes up. Plugging or unplugging the cable switches the transport without restarting.

While USB is connected the keyboard never goes to sleep, since it is powered by the port.

Polling interval9 msCONFIG_USB_HID_POLL_INTERVAL_MS

The first three are set in app/prj.conf. The polling interval is the Zephyr default; add the symbol to app/prj.conf to change it.

Reports

  • The keyboard report carries the eight modifiers and up to six keys held at the same time.
  • A second report carries media keys, also up to six at a time.

The same reports are used over Bluetooth, so the keyboard behaves identically on both transports.

Options

Set them in keyboard.h:

OptionDefaultMeaning
USBtrueIncludes the USB keyboard transport. With false, keys are only sent over Bluetooth.
USB_CHECK_TIMEOUT1000Time in ms between checks of the USB cable while the keyboard is awake.

USB serial for logs

When the firmware is built with LOGS, the keyboard also appears as a USB serial port that prints log messages. See Logs.
