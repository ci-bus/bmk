How a build is assembled

  1. -b selects the board folder in app/boards/arm, with the chip, the flash layout and the base configuration.
  2. app/prj.conf adds the settings shared by all targets.
  3. -DKEYBOARD selects the keyboard folder. Its keyboard.c and keymap.c are compiled together with src/main.c.
  4. If keyboard.h enables RGB or LOGS, the matching overlay and configuration from boards/arm/common are added.
  5. With -DKEYBOARD=dongle, the build compiles src/dongle/main.c instead and adds src/dongle/dongle.conf on top of prj.conf.
