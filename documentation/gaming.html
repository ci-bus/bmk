Gaming mode

Gaming mode scans the matrix much more often, trading battery life for a lower delay between pressing a key and sending it.

Switching it on and off

Put these two keycodes somewhere in your keymap, usually on a secondary layer:

KeycodeAction
HID_GAMING_ONEnables gaming mode.
HID_GAMING_OFFDisables gaming mode.

Gaming mode is always off when the keyboard starts. Switching it releases every key that was held.

What changes

NormalGaming mode
Pause between matrix scansCYCLE_DELAY (1000 µs by default)GAMING_CYCLE_DELAY (100 µs by default)
GUI keys (Windows key)Work normallyIgnored, so they cannot take you out of a full-screen game

Both GUI keys are ignored, also when they are the hold action of a tap-hold key. The other modifiers keep working.

The debounce and tap-hold times are recalculated for the new scan rate, so they keep the same duration in milliseconds.

With the default values the pause between scans is ten times shorter, so the processor rests less and the battery drains faster. Switch gaming mode off when you finish playing.

Options

Set them in keyboard.h:

OptionDefaultMeaning
CYCLE_DELAY1000Pause in µs between two matrix scans in normal mode.
GAMING_CYCLE_DELAY100Pause in µs between two matrix scans in gaming mode.
