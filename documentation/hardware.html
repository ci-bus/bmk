Boards and hardware

BMK defines its own two boards inside the repository. They describe the chip, the memory layout and the clock, and are shared by every keyboard that uses that chip.

Boards

BoardChipFolder
nrf52840nRF52840 (QIAA)app/boards/arm/nrf52840
nrf52833nRF52833 (QIAA)app/boards/arm/nrf52833

The nRF52840 board was written for the Ebyte E73-2G4M08S1C module, which has a ceramic antenna and exposes most pins of the chip.

What both boards have in common

  • Clock: the 32.768 kHz clock comes from the internal RC oscillator. No external low-frequency crystal is needed.
  • Supply: the firmware expects the chip to be powered through its high-voltage input (VDDH), from USB or from the battery. The battery level is measured on that input.
  • USB: the USB controller of the chip is enabled; the UART is disabled.
  • Wake-up: every pin of both GPIO ports can wake the keyboard from sleep, so any pin can be a matrix row.
  • Bootloader: Adafruit nRF52 UF2 bootloader. The firmware is built as a UF2 file and starts at address 0x1000.
  • Storage: Bluetooth pairing data is kept in a dedicated flash area, separate from the firmware.

On the nRF52840 the firmware also enables the internal DC/DC converter at start-up.

Key matrix

  • Columns are outputs, driven high one at a time. Rows are inputs with the internal pull-down enabled.
  • Each switch needs a diode with its cathode towards the row.
  • Any GPIO of port 0 or port 1 can be a column or a row.

See Adding a keyboard for how the pins are declared.
