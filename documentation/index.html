BMK firmware

BMK stands for Bluetooth Mechanical Keyboard: a firmware for mechanical keyboards built on Nordic nRF52840 and nRF52833 modules. It runs on Zephyr RTOS 3.6 and works over USB and Bluetooth Low Energy.

Features

  • USB and Bluetooth: HID keyboard over USB when the cable is plugged in, over Bluetooth Low Energy on battery. See USB and Bluetooth.
  • Layers: momentary and permanent layer switching, with transparent keys. See Keymaps and layers.
  • Tap-hold keys: one key that sends a keycode when tapped and acts as a modifier when held. See Tap-hold.
  • Rotary encoder and media keys. See Encoders and Keycodes.
  • RGB lighting with WS2812 LEDs. See RGB lighting.
  • Battery level reported to the host over Bluetooth. See Battery.
  • Power saving: the keyboard sleeps when idle and wakes up on a key press. See Sleep and power.
  • Gaming mode: a faster matrix scan that you switch on from the keymap. See Gaming mode.
  • USB dongle: a second firmware that receives a keyboard running BMK over Bluetooth and presents it to the computer as a USB keyboard. See USB dongle.
  • UF2 flashing: updating the firmware is copying a file to a USB drive. See Flashing.

Supported hardware

The firmware targets two boards, both defined inside the repository. The keyboard PCBs accept a module with either chip, so every keyboard can be built for both boards:

BoardChipUsed by
nrf52840nRF52840Keyboards and the USB dongle
nrf52833nRF52833Keyboards

The keyboards included in the repository live in app/keyboards:

KeyboardMatrixExtras
miguelio/mk60v18 columns × 9 rowsEncoder, RGB, switchable external power
miguelio/mk60v28 columns × 9 rowsEncoder
miguelio/aether7515 columns × 6 rowsEncoder, RGB, switchable external power

Any other PCB with one of these chips can be supported by adding a keyboard. Details about the boards are in Boards and hardware.

How the documentation is organised

  • Getting started takes you from an empty machine to a flashed keyboard.
  • Keymaps explains how to decide what every key does.
  • Features describes what the firmware does on its own and which keys control it.
  • Reference lists every configuration option and the layout of the source tree.
  • Development covers new keyboards, the board definitions and debugging with logs.
